# FixMyHostel

A Hostel Complaint Management System

FixMyHostel is a web-based application designed to simplify hostel complaint management by connecting students, maintenance workers, and hostel management through a centralized platform.

## Features

- Student Dashboard: Submit hostel complaints and track their status.
- Complaint Tracking: Monitor complaint progress and priority.
- Search and Filtering: Find and filter complaints by status, priority, date, category, and assigned worker.
- Worker Dashboard: View assigned complaints and update their progress.
- Management Dashboard: Manage complaints and coordinate maintenance tasks.
- Complaint Review: Review completed work and approve or reject it.
- Media Attachments: Allow students to attach photos to complaints and require workers to upload completion photos after finishing a task.
- Scheduling: Organize and manage maintenance tasks.
- Feedback and Notifications: Allow students to provide feedback on completed work and keep users informed about complaint updates.

## Tech Stack

- Frontend: HTML, CSS, JavaScript
- Backend: Node.js, Express.js
- Database: SQLite

## Getting Started

### Prerequisites

Install Node.js before running the application: https://nodejs.org/

### Installation

1. Clone the repository:

bash
git clone https://github.com/kashishhMishra/fixmyhostel-latest.git


2. Open the project folder:

bash
cd fixmyhostel-latest


3. Install dependencies:

bash
npm install


4. Start the server:

bash
node server.js


5. Open http://localhost:3000 in your browser.

## Project Objective

FixMyHostel aims to make hostel maintenance more organized, transparent, and efficient by bringing complaint submission, assignment, progress tracking, and review into one platform.

## Future Improvements

- AI-Powered Smart Assignment and Scheduling: Use AI-assisted priority assessment to recommend suitable maintenance workers and appointment times based on complaint urgency, worker skills, workload, availability, and students' preferred time slots.
- Online Deployment: Deploy the application so students, workers, and hostel management can access it through a live website.
- Enhanced Authentication and Authorization: Improve login security and implement role-based access control for students, workers, and management.
- Workload Balancing: Distribute complaints fairly among available workers based on their skills and existing assignments.
- Automatic Rescheduling: Suggest alternative appointment times when students or workers become unavailable.
- Analytics and Reporting Dashboard: Display complaint statistics, resolution times, pending requests, and worker performance.
- Complaint History and Tracking: Maintain a detailed history of complaint updates, assignments, and resolutions.
- Mobile Responsiveness: Improve usability across mobile phones, tablets, and desktops.
